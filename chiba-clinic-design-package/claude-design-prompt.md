# Claude Code Designへの依頼文

添付の参考画像の雰囲気をもとに、「ちば内科クリニック」のWebサイトUIデザインを作成してください。

今回は本実装ではなく、実装しやすいWebサイトUIデザインの制作が目的です。PC版とスマホ版の両方を考慮し、レスポンシブ化しやすい構成にしてください。

## 参考デザインの方向性

参考画像は、深緑、白、淡いグリーンを基調にした、やさしい医療サイトです。完全なピクセル再現ではなく、構成、色、余白、清潔感、地域密着感、家族で通える安心感を優先して再現してください。

医療サイトなので派手すぎる装飾、強いグラデーション、過度なアニメーション、広告的な煽り表現は避けてください。

## 使用画像

以下の画像が `assets/images/` に配置される前提でデザインしてください。

- `assets/images/hero-clinic.jpg`: ファーストビュー右側のクリニック外観画像。
- `assets/images/doctor-profile.jpg`: 院長紹介カードのプロフィール画像。
- `assets/images/access-map.png`: アクセスカード内の簡易マップ画像。
- `assets/images/green-blur-bg.jpg`: ファーストビュー左側や背景に使う淡いグリーンのぼけ背景。

画像が未配置の場合でも、同名ファイルに差し替えれば成立するように、画像枠、比率、トリミング方針を明確にしたUIにしてください。

画像の扱いは以下を目安にしてください。

- `hero-clinic.jpg`: PCではファーストビュー右側に大きく表示し、建物入口が見える横長トリミングにする。SPでは最初に画像を見せ、その下にキャッチコピーを置く。
- `green-blur-bg.jpg`: PCファーストビュー左側の背景として淡く使い、文字の可読性を優先して白い余白や薄い白オーバーレイを使う。
- `doctor-profile.jpg`: 院長紹介カード内で、顔と白衣が自然に見えるように表示する。実在本人写真ではない場合は「院長イメージ」ではなく、デザイン上の仮素材として扱う。
- `access-map.png`: アクセスマップカード内で16:10から3:2程度の比率で表示し、下に注意書きを置く。Google Mapsのスクリーンショット風に寄せすぎず、簡易マップ素材として扱う。

## PCレイアウト指示

- ヘッダーは上段に医院名、住所、電話番号を横並びで配置し、電話番号を最も見つけやすくする。
- ナビゲーションはヘッダー下に横並びで配置し、参考画像のように細い区切り線を使う。
- ファーストビューは左右2カラムにし、左40%前後にキャッチコピー、右60%前後に外観画像を配置する。
- クリニック紹介と院長紹介は2カラムにし、本文量が多くても読み疲れないよう段落、行間、余白を十分に取る。
- 下部の「診療時間」「最寄りアクセス」「アクセスマップ」は3カード横並びにする。3カードの高さと角丸感をそろえる。

## スマホレイアウト指示

- ヘッダーは医院名、電話番号、住所を縦並びにする。電話番号はタップしやすい大きさにする。
- ナビは縦並び、または折りたたみを想定した見た目にする。
- 表示順は、外観画像、キャッチコピー、3つの特徴、クリニック紹介、院長紹介、診療時間、アクセス、地図、訪問診療、フッターとする。
- PCの横並び要素はすべて1カラムに積む。カード間の余白を十分に取り、窮屈に見せない。

## 診療時間表の指示

診療時間は表形式で見やすく整理してください。PCでは曜日を横軸、時間帯を縦軸にします。SPでは表が読みにくい場合、横スクロールではなくカード型の補助表示を追加してもかまいません。

推奨表記:

| 9:00-12:00 | ○ | ○ | ○ | ○ | ○ |
| 13:30-16:30 | ○ | - | ○ | ※1 | ○ |
| 14:30-16:30 | - | - | - | ※2 | - |
| 17:00-19:00 | - | - | - | ○ | - |

補足:

- ※1 第1、3木曜 13:30-16:30 / 17:00-19:00

- 休診日: 土曜・日曜・祝日

木曜の診療時間が週によって異なる点が分かるよう、表の下に注記を必ず入れてください。

## 院長紹介カードの指示

- カード内には `doctor-profile.jpg`、氏名「院長／千葉 淳氏」、経歴、院長コメントを含める。
- PCでは画像とテキストを横並び、または画像上部・テキスト下部のカード型にする。どちらの場合も、氏名が最初に目に入るようにする。
- 経歴は長文にせず、4から5行程度で読みやすく整理する。
- 院長コメントは淡いグリーン背景の引用風ボックスに入れ、参考画像のように安心感のある見せ方にする。

## アクセス表示の指示

- 最寄りアクセスカードでは「くしろバス大楽毛2丁目停留所から徒歩5分」を大きく表示する。
- アクセスマップカードでは `access-map.png` を表示し、下にGoogle Mapsマーカーのズレに関する注意書きを掲載する。
- 住所「釧路市大楽毛2丁目2-27」と電話番号「0154-64-6650」はアクセス周辺でも再掲してよい。
- 地図は目安であることが伝わるよう、正式な地図利用は本番実装時に確認する前提にする。

## UI要件

- 診療時間表とアクセス情報を特に見やすくしてください。
- 高齢者にも読みやすい文字サイズ、行間、コントラスト、余白にしてください。
- 電話番号はPCでもスマホでも見つけやすくし、スマホではタップしやすい表示にしてください。
- 全体は白と淡いグリーンの余白を多く使い、深緑を見出し、ボタン、区切り、重要情報に使ってください。
- カードは丸みを少しつけ、影は弱く、医療サイトらしい清潔な印象にしてください。
- 最終的にHTML/CSSへ実装しやすい、整理されたコンポーネント構成にしてください。
