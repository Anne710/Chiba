# デザイン仕様

## 基本方針

「ちば内科クリニック」は、釧路市大楽毛地区の地域医療を支える内科クリニックです。デザインでは、家族で通える安心感、地域に根ざした信頼感、訪問診療にも対応する頼もしさを表現してください。

添付の参考画像は、深緑、白、淡いグリーン、やわらかな自然背景、クリニック外観写真、丸みのある医療アイコンを組み合わせた穏やかな医療サイトです。ピクセル単位の一致ではなく、余白、配色、読みやすさ、清潔感を優先してください。

### 色の使い方

- `--main-green`: ロゴ、見出し、電話番号、主要ボタン、強調テキスト。
- `--soft-green`: カード背景、引用コメント、特徴エリアの背景。
- `--light-green`: セクション背景、ファーストビュー左側の淡い背景。
- `--accent-green`: アイコン、補助ボタン、装飾線。
- `--text-main`: 本文の基本色。
- `--text-sub`: 補足説明、注記、サブコピー。
- `--line-beige`: ナビ区切り線、表の罫線、控えめな装飾。
- `--cream`: 診療時間カードやアクセスカードなどの温かい背景。

## レイアウト方針

- 最大幅はPCで約1100pxから1200pxを目安にする。
- 白背景を基本に、淡いグリーンの背景帯でセクションを分ける。
- ファーストビューは左にキャッチコピー、右にクリニック外観画像。
- クリニック紹介と院長紹介は横並びにし、スマホでは縦積みにする。
- 診療時間、最寄りアクセス、アクセスマップはPCで3カード、スマホで縦並び。
- 重要情報である電話番号、診療時間、住所は視認性を高くする。

## 診療時間表の表示ルール

PCでは次の構成を基本にしてください。

| 時間帯 | 月 | 火 | 水 | 木 | 金 |
| --- | --- | --- | --- | --- | --- |
| 9:00-12:00 | ○ | ○ | ○ | ○ | ○ |
| 13:30-16:30 | ○ | - | ○ | ※1 | ○ |
| 14:30-16:30 | - | - | - | ※2 | - |
| 17:00-19:00 | - | - | - | ○ | - |

- ※1 第1、3木曜 13:30-16:30 / 17:00-19:00
- ※2 第2、4木曜 14:30-16:30 / 17:00-19:00
- 休診日: 土曜・日曜・祝日

スマホでは表が小さくなりすぎないよう、文字サイズを確保してください。必要であれば、表の下に「木曜は週により午後開始時間が異なります」のような短い補足を追加してください。

## 主要カードの仕様

- 院長紹介カード: 画像、氏名、経歴、コメントを1つのカードにまとめる。コメントは淡いグリーンの引用風ボックスにする。
- 診療時間カード: カレンダーまたは時計アイコン、表、注記、休診日を含める。
- 最寄りアクセスカード: バスまたは徒歩アイコンと「徒歩5分」を大きく表示する。
- アクセスマップカード: 地図画像、注意書き、必要に応じて住所を含める。
- 訪問診療カードまたは帯: 通院が困難な方にも相談できる印象にし、対象や効果を断定しすぎない。

## 避ける表現

- 「絶対治る」「必ず改善」など、効果を保証する表現。
- 過度に不安を煽る表現。
- 派手な装飾、強い点滅、広告バナー風の見せ方。
- 実在の医師写真がない場合に、AI生成画像を本人写真と断定する表現。
