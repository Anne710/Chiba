# Image2用 画像生成プロンプト

生成した画像は `assets/images/` に以下のファイル名で配置してください。

## hero-clinic.jpg

用途: ファーストビュー右側のクリニック外観画像  
サイズ目安: 1600 x 900px

```text
地方の内科クリニックの外観写真風イメージ。
平屋〜低層のクリニック建物、木目とベージュ系の外壁、深いグリーンの屋根ライン。
入口には自動ドア、バリアフリーのスロープ、清潔感のある植栽。
北海道の地方都市にある地域密着型クリニックの雰囲気。
明るい昼間、青空、やわらかい自然光。
医療サイトのファーストビューに使える横長構図。
人物なし。
文字なし。
リアル寄り、清潔感、安心感、やさしい雰囲気。
```

## doctor-profile.jpg

用途: 院長紹介カード  
サイズ目安: 800 x 900px  
注意: 実在の千葉院長本人として断定せず、イメージ写真として扱う。

```text
日本人の中年男性医師のプロフィール写真風。
白衣を着て、診察室で穏やかに座っている。
やさしい表情、信頼感、地域のかかりつけ医の雰囲気。
背景は明るい診察室、清潔感のある医療機器や書類棚が少し見える。
医療サイトの院長紹介に使える自然な写真。
リアル寄り、上品、安心感。
文字なし。
```
