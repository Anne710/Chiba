# アイコン候補一覧

UI内のアイコンは、SVGまたはCSSで作成してください。線は細すぎず、丸みのあるやさしい形にし、色は `#2f6b3f` または `#7fa36b` を基本にしてください。

## 必須に近いアイコン

- ロゴ風アイコン: 葉、木、ハート、医療の安心感を連想する抽象マーク。
- 家族サポート: 大人と子ども、家族、複数人。
- 内科全般: 聴診器、十字、診察。
- 訪問診療: 家、医療バッグ、十字。
- 診療時間: カレンダー、時計。
- 電話: 受話器。
- 住所: 地図ピン。
- 最寄りアクセス: バス、徒歩、道筋。
- アクセスマップ: 地図ピン、簡易地図。

## 表現ルール

- アイコンだけが目立ちすぎないようにする。
- 医療サイトらしく、信頼感と読みやすさを優先する。
- 丸型の薄いグリーン背景にアイコンを入れると、参考画像に近い雰囲気になる。
- スマホではアイコンと短いラベルをセットにして、意味がすぐ分かるようにする。
