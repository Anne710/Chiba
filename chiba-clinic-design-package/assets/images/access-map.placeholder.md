# access-map.png プレースホルダー

## 用途

アクセスカード内に配置する簡易マップ画像です。

## 配置先ファイル名

`assets/images/access-map.png`

## サイズ目安

900 x 600px

## 内容

淡い色のシンプルな地図。中央に赤いピン、周辺に道路やバス停などの簡単な目印。文字なし。

## デザイン上の使い方

アクセスマップカード内に横長で表示します。画像の下には、Google Mapsマーカーのズレに関する注意書きを小さく掲載してください。

## 注意

Google Mapsのスクリーンショットを無断で使用しないでください。本番ではGoogle Maps埋め込み、または公式に利用可能な地図素材を使ってください。

## 差し替え方法

画像生成または正式な地図素材を用意したら、この説明ファイルは残したまま、同じフォルダに `access-map.png` を配置してください。
